# Checkout

Páginas de checkout do Método Greco, replicadas visualmente a partir do checkout original (Kiwify), sem scripts de tracking, IDs ou dados internos de plataforma de terceiros.

São páginas independentes — não há navegação entre elas.

- [`checkout-mensal.html`](checkout-mensal.html) — assinatura mensal (R$ 44,17/mês)
- [`checkout-parcelado.html`](checkout-parcelado.html) — pagamento único parcelado em até 12x (R$ 356,97 à vista)
- `extras-tooltip-notification.css` — CSS auxiliar extraído do checkout original (tooltips, notificações, ícones), não utilizado pelas páginas acima, mantido como referência.
